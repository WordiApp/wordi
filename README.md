# Wordi Web App

A unique take on learning vocabulary with an aesthetic, easy-to-use web app! This was my Independent CS project created throughout the course of my High School Senior year. 

The primary purpose of this project was to familiarize myself more with the three core web programming languages (HTML, CSS, JS), work on my notation and documentation, discover some cool algorithms, and create a usable product.

## 🚀 Features

- Dynamic bootstrap navbar with easy navigation and mobile support
- Account system with login, register, update details, forgot password, and delete account capabilities
- Dashboard page that displays a user's stats, an integrated Google calendar, and a GLOBAL leaderboard
- Dictionary page that allows users to look up definitions to words or learn a random new word
- Dictionary search history that allows users to return to their previous searches
- Games tab, featuring three games...
    1. Quiz: Define as many words as you can in a multiple-choice format in 30 seconds!
    2. Search: Free-range word search game that regenerates a new grid once you find the hidden word!
    3. Link: Chain words that start with the same letter that the previous word ended with!
- Earn points for searching words or playing games
- Custom notification system

## 🔧 Technologies Used

- JavaScript (ES6+)
- HTML5
- CSS
- Firebase Realtime Database
- JSON data formatting
